# Flow of all screens (see images/FLOW_all_screens.png)

| From | Action | To | Roles |
|---|---|---|---|
| Welcome | Sign in with SRM | Super Admin Today (Students are not Admin) | Super Admin |
| Welcome | Staff sign in | Food Head Today | Food Head |
| Tab bar | Today, Students, Results, More | the four tab roots | both |
| Tab bar | Search button | Search | Super Admin only |
| Today | Mess tile | Headcount · Lunch (page, DRAFT) | both (Food Head: Main only) |
| Today | Approve | Approved state of Headcount · Lunch | both |
| Today | Change the number | Change the number sheet, then back to Today | both |
| Today | Needs you · Review | Meal report (existing frame) | both |
| Today | Needs you · Remind | Remind sheet (existing frame) | Super Admin |
| Headcount · Lunch | tap a card | the six detail sheets (DRAFT) | both |
| Students | Remind N students | Remind sheet (existing) | both |
| Students | Feedback tile | Feedback · Sambar page (existing) → Reply or Make it a change | both |
| Students | Community tile | Community issue page (existing) | both |
| Students | Skipped tile, By mess tile | Why students skip, per-mess answers | Super Admin only |
| Results | Left over, Ran out, To check | the three segments | both |
| Results | a reason row | Reason detail sheet (existing) | both |
| Results | Review a meal | Meal report (existing) | both |
| Results | Weekly report | Weekly report (existing) → Report ready, Export PDF, CSV | both |
| Results | Find an older meal, Safety cases | existing frames | both |
| More | each row | existing destination frames (Weekly menu → Edit day, Wednesday pass, Outings, Votes, Rewards, Spare food, Announce, History) | both |
| More | People and access | the existing People and access frames, unchanged | Super Admin only |
| More | Sign out | Welcome | both |
